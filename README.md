# Лабораторная работа №4 — Unit-тестирование

Проект продолжает лабораторную работу №2: тестируются функции вычисления
площади и периметра окружности, квадрата и треугольника.

## Что делает проект

В модулях реализованы функции `area(...)` и `perimeter(...)` для трёх фигур.
Для каждой функции написаны модульные тесты на стандартной библиотеке
`unittest`. Тесты проверяют корректность вычислений на целых числах,
числах с плавающей точкой и граничных значениях (например, сторона = 0).

## Структура

```
.
├── circle.py          # площадь и периметр окружности
├── square.py          # площадь и периметр квадрата
├── triangle.py        # площадь и периметр треугольника
├── test_circle.py     # тесты для circle.py
├── test_square.py     # тесты для square.py
├── test_triangle.py   # тесты для triangle.py
└── README.md
```

## Запуск всех тестов

Из корня проекта выполните:

```bash
python -m unittest -v
```

Флаг `-v` (verbose) печатает имя каждого теста и его результат
(`ok` / `FAIL` / `ERROR`).

## Что проверяют тесты

Для каждой фигуры покрыты как минимум три случая:

| Случай                    | Пример для квадрата      |
|---------------------------|--------------------------|
| Положительное целое число | `area(5) == 25`          |
| Ноль (граничное значение) | `area(0) == 0`           |
| Число с плавающей точкой  | `area(2.5) == 6.25`      |

Аналогично проверяется `perimeter(...)`.

## Ожидаемый результат

При успешном прохождении всех тестов выводится примерно следующее:

```
test_area_float_side (test_square.SquareTestCase.test_area_float_side) ... ok
...
----------------------------------------------------------------------
Ran N tests in 0.00Xs

OK
```

Если какой-то тест падает, `unittest` покажет имя теста, ожидаемое и
фактическое значение — это помогает быстро найти ошибку в реализации.
